# План SpiritJeronion

## Уже подготовлено

- получение расписания и домашних заданий из МЭШ;
- синхронизация уроков с Google Calendar без дубликатов;
- чтение личной Gmail и пересланной лицейской почты;
- выжимка новостей;
- изменение календаря с подтверждением;
- каркас индексации PDF-учебников;
- адаптивный веб-интерфейс.

5. Подключить решение упражнений и подготовку конспектов.
6. Добавить вход владельца и постоянный адрес сайта.
