# Архитектура

```text
Веб-интерфейс
      |
      | /api/assistant
      v
Серверный прокси сайта
      |
      | X-Spirit-Key
      v
n8n Webhook
  |-- МЭШ parser
  |-- Google Calendar
  |-- Gmail
  |-- Ollama
  `-- хранилище учебников
```

Браузер никогда не получает OAuth-токены, cookie МЭШ или общий ключ. Внешние запросы выполняются только серверной частью сайта и n8n.
