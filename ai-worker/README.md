# SpiritJeronion AI Worker

Локальное ядро ассистента. Оно принимает сведения из n8n, сохраняет источники, создаёт предложения изменений и применяет их только после подтверждения пользователя.

## Запуск

```powershell
cd C:\SpiritJeronion\ai-worker
.\start.ps1
```

По умолчанию сервис работает только локально на `http://127.0.0.1:8899` и использует Ollama `qwen3:8b`.

## Основные запросы

- `GET /api/health` — состояние сервиса.
- `GET /api/state` — задачи и очередь подтверждений.
- `POST /api/intake` — разобрать новое сообщение или документ.
- `POST /api/proposals/{id}/decision` — подтвердить или отклонить предложение.

Настоящая база создаётся в `C:\SpiritJeronion\.spirit-data` и исключена из Git.

Вложения принимаются только из локальных каталогов `uploads` и `textbooks`. Текстовые файлы читаются сразу; для извлечения текста PDF можно дополнительно установить `pypdf`. Фотографии регистрируются с источником, а OCR будет подключён следующим модулем.
