# SpiritJeronion — главный workflow n8n

Файл `SpiritJeronion.json` — главный центр управления ассистентом. Сборщики, Groq, очередь подтверждений и маршрутизация находятся в n8n; Python используется только там, где нужны `schoolmospy`, локальная файловая память или `ChatGPTAutomation`.

## Уже реализовано в skeleton

- Gmail Trigger для `jeronion2010@gmail.com`: раз в минуту читает новые непрочитанные входящие, включая пересланные со школьной почты, сохраняет метаданные вложений и не меняет состояние письма.
- GramPro Trigger 6.0.4 для входящих Telegram-сообщений из личных чатов, групп и каналов; медиа сохраняются как binary-вложения.
- Периодический вызов локального Python-адаптера МЭШ.
- Настоящий диалоговый webhook сайта через Groq: `POST /webhook/sj-chat`.
- Распознавание через Groq Chat Completions.
- Единая схема: `event`, `homework`, `news`, `task`, `unknown`.
- Очередь предложений во static data workflow.
- GET webhook очереди и POST webhook решения.
- Маршрутизация подтверждённых предложений по обработчикам.

## Заглушки

- Google Calendar create/update.
- Сводка задач.
- Генератор `.md` конспектов.
- Локальный адаптер ChatGPTAutomation.
- Хранилище новостей.

## Перед первым запуском

1. Открыть `C:\SpiritJeronion\.env` и локально заполнить ключ Groq и секрет очереди.
2. Запустить `..\mesh_service\setup.ps1`, затем `..\mesh_service\start.ps1`.
3. Запустить n8n через `start.ps1`, чтобы переменные из `.env` попали в процесс.
4. Импортировать `SpiritJeronion.json` через **Import from File**.
5. Подключить Google credential к `Gmail — collect unread`.

Чат принимает JSON вида:

```json
{"text":"Добавь контрольную по физике завтра в 10:00","history":[]}
```

Ответ содержит `reply`, `proposals` и `queued`. Даже предложение из чата сначала попадает в очередь подтверждения.

Секреты нельзя вставлять в JSON или коммитить в GitHub.

`start.ps1` разрешает workflow читать переменные процесса, потому что n8n 2.x по умолчанию блокирует `$env`. Поэтому импортируйте только доверенные workflow: любой активный Code/Expression node теоретически сможет прочитать эти переменные.
