# SpiritJeronion MESH parser

Локальный HTTP-сервис между n8n и личным аккаунтом Московской электронной школы. Возвращает только расписание и домашние задания; профиль, телефон, документы и другие лишние данные наружу не передаются.

> Интеграция неофициальная: публичного стабильного API для личного дневника нет, поэтому МЭШ может изменить внутренние методы. Используйте сервис только со своим аккаунтом.

## 1. Настройка

1. Скопируйте `.env.example` в `.env`.
2. Войдите в `https://school.mos.ru` в браузере.
3. Откройте инструменты разработчика → Application/Приложение → Cookies → `https://school.mos.ru`.
4. В текущей версии сайта скопируйте значение cookie `aupd_token` в `MESH_TOKEN`, а числовое значение `active_student` — в `MESH_STUDENT_ID`. На старой версии сайта эти cookies могли называться `auth_token` и `student_id`.
5. Не отправляйте эти значения в Telegram, чаты или скриншоты. Файл `.env` исключён из Git.
6. Если и n8n, и парсер работают прямо в Windows, `MESH_SERVICE_KEY` можно временно оставить пустым: сервис доступен только с этого компьютера. Для Docker или доступа по сети ключ обязателен.

## 2. Запуск

```powershell
cd C:\SpiritJeronion\mesh-parser
npm install
npm start
```

Проверка без обращения к МЭШ:

```powershell
Invoke-RestMethod http://127.0.0.1:8787/health
```

Запрос к МЭШ:

```powershell
$body = @{ request = '/mesh' } | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8787/mesh -ContentType 'application/json' -Body $body
```

## 3. Подключение n8n

- n8n на Windows: `meshParserUrl = 'http://127.0.0.1:8787/mesh'`.
- n8n в Docker: установите `MESH_HOST=0.0.0.0`, перезапустите сервис и используйте `meshParserUrl = 'http://host.docker.internal:8787/mesh'`.
- Если задан `MESH_SERVICE_KEY`, в узле `MESH parser endpoint` включите Header Auth и передавайте `X-Mesh-Key`. Секрет храните в credential n8n, не в Code-узле.

Команда `/mesh` возвращает обзор недели. Обычные запросы вроде «покажи расписание МЭШ на завтра» или «домашнее задание МЭШ на завтра» ограничивают ответ нужным разделом и периодом.

## Безопасность

- Сервис по умолчанию слушает только `127.0.0.1`.
- При прослушивании не только локального адреса запуск без `MESH_SERVICE_KEY` блокируется.
- Тело запроса ограничено 32 КБ.
- Токен никогда не попадает в ответ или журнал.
- При заданном `MESH_SERVICE_KEY` запросы без правильного ключа отклоняются.
- При истёкшем токене сервис один раз пытается обновить его в памяти; если МЭШ отклонит обновление, получите `MESH_AUTH_FAILED` и потребуется скопировать свежий `aupd_token`.
